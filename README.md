# RAGenius Generative AI Course Context Engine 🎓

An AI-powered backend teaching assistant built to process educational course videos. It uses a Retrieval-Augmented Generation (RAG) pipeline to ingest course material, transcribe it, and intelligently answer student queries or generate MCQ quizzes in a friendly **Hinglish** tone.

The system relies entirely on local processing via **OpenAI Whisper** and **Ollama**, ensuring privacy and zero API costs.

---

## 🚀 Features

* **Automated Data Pipeline:** Extracts audio from video files and chunks them into manageable JSON metadata files.
* **Offline Transcription:** Uses OpenAI's Whisper (`medium` model) to transcribe Hindi speech and translate it to English context.
* **Local RAG Architecture:** * Generates embeddings via Ollama (`bge-m3`).
  * Uses `joblib` and `scikit-learn` cosine similarity for fast vector search.
  * Generates answers and quizzes via Ollama (`llama3.2`).
* **Interactive API Endpoints:** Built with FastAPI, offering endpoints for Q&A (chat/summary modes) and automated quiz generation.
